# Demo Video Script (≤ 3 minutes)

> Educational project for the course Introduction to Finance. Not a real product, service or investment offer. Do not use with real funds.

**Before recording**

- Run `npm run dev:fresh` in a terminal (it starts the node, deploys, seeds and starts everything). Wait for "SecureVote is running".
- **Never show** the `.env` file, `.run/hardhat-node.log`, or the raw `npx hardhat node` output: they contain the demo password / Hardhat's public test private keys.
- Use two browser windows (or one normal + one private window) to switch users faster. Zoom to 110 % for readability.
- Have a second terminal ready in the project folder for the test run.
- The video is uploaded **manually** to the university OneDrive; paste the link into the README afterwards.
